| 1440×900 深色，同上 | 同上，曲线保留，tooltip 底色 `rgba(40,40,40,0.95)` |
| 真实点击图例隐藏 `电信` 后 | 该序列消失、图例标记转灰，其余三条不受影响——这是**正常的图例隐藏**，与「绘制丢失」是两回事 |

| 悬浮移出 | 曲线像素不变 |

可复现的**相关事实**：tooltip 为 `confine: true`（上游 `LoadChart` 的 `baseTooltipConfig` 是 `confine: false`），

这能解释「看起来像消失」的观感，但不构成曲线本身消失，本轮**不据此改动 tooltip 配置**。

未覆盖：移动端真实触摸（浏览器面板在该时段不可见，动作超时）、实时更新过程中的长时间观察、多序列大量交叠。
