### K 本地浏览器时间线

在独立的 `localhost:4182` origin、配置延迟 1500ms 的 mock 中，临时模拟北京时间白天（`getUTCHours() = 2`）；system 场景另模拟系统深色。mock 的 HTML 临时埋点记录 `performance.now()` 和 `data-theme` 变化，测后已移除埋点。以下毫秒均相对本次导航起点：

| 场景 | `data-theme` 记录 |
|---|---|
| 清空存储后首次访问 dark | 90.7ms `light` → 1659.8ms `dark` |
| 再次访问 dark | 82.7ms `dark`，没有浅色阶段 |
| 站点改 light | 78.0ms `dark` → 1636.6ms `light`，只切一次 |
| 再次访问 light | 138.7ms `light`，没有深色阶段 |
| 站点改 system、模拟系统深色 | 81.1ms `light` → 1635.0ms `dark`，只切一次 |
| 再次访问 system | 83.5ms `dark`，没有与系统相反的阶段 |

首次访问 dark 那次，`data-theme=light` 于 90.7ms 生效，浏览器 `first-paint` 为 132.0ms、`first-contentful-paint` 为 164.0ms：JS 生效比首次绘制早约 **41.3ms**，本次测量没有“首次绘制后、JS 生效前”的可见空窗。不同设备和缓存条件可能不同；HTML 未注入生产脚本，JS 执行前的时段不能由主题保证。

### 自定义背景：测量与用户追加修复

本地 mock 临时令 `backgroundEnabled=true`，明暗自定义 URL 都指向 mock 的 SVG，配置延迟 1500ms；仅此测量采用虚构路径，不含真实站点地址。修复前：默认背景约 120.7ms 发请求、127.9ms 显示；自定义背景约 1640.6ms 显示、1641.1ms 请求。修复后：约 100.9ms 为空背景层，1696.2ms 直接进入自定义背景，资源列表只有自定义 SVG（1696.5～1703.8ms），没有默认图请求。配置明确失败的对照：约 1632.4ms 显示默认背景，1634.6ms 才请求默认图。临时 mock 改动与埋点均已移除；没有向生产 bundle 添加测试代码。
