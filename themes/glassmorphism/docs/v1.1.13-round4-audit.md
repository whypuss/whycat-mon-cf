# v1.1.13 候选第四轮 O：背景层审计

> 范围仅是背景层按上游 `Background.vue`（`bf83765`）移植。本文件不是发布说明；`package.json` 保持 `1.1.12`。正式提交、CI 与 `preview-main` SHA 在推送后的交付回复中核对。

## 七项差异的结论

| # | 原差异 | 本轮结果 |
|---:|---|---|
| 1 | 图片未预加载、默认层过早卸下 | 与上游相同：`new Image()` 加载成功才挂媒体层；首访期间默认图持续在场，错误时不挂媒体。已知自定义背景的再访遵守用户要求的冷启动请求门，先留空，不请求默认图。 |
| 2 | 缺少过渡 | 默认、加载、回退、媒体四层均由 `<Transition name="fade">` 管理；fade 与媒体自身的 opacity 过渡都是 `0.8s ease`。既有 `data-motion='reduced'` 全局规则仍可缩短过渡。 |
| 3 | 图片失败空白 | `hasError` 后显示/保留默认图；404 首访和再访都已在浏览器验证。 |
| 4 | 视频缺少加载层/错误回退 | 媒体先以 `opacity:0` 挂载；加载层按明暗取上游样式；`loadeddata` / `canplay` 后显示，`error` 后默认层与回退层在场；`preload="auto"`。 |
| 5 | blur 额外缩放 | 模糊为 `filter: blur(Npx)`，零值为 `none`；媒体 `transform:none`。 |
| 6 | 负遮罩叠白且默认层不受影响 | 正数在所有背景之上叠黑层；负数降低整个背景容器透明度；零值不挂遮罩。设置矩阵 47/48 已纠正。 |
| 7 | 容器 `z-index:-2` 与自带渐变底色 | 对齐上游 `z-index:-1`、`background-image:none`；所有图层留空时露出 `html --background`，`body` 透明。1280px 浅色同为 `oklch(0.935 0.015 252)`，暗色同为 `oklch(0.141 0.005 285.823)`。骨架与毛玻璃面板无须依赖旧渐变。 |

必要 CFSM 差异集中记录在 `docs/fidelity-audit.md` #33：Vite `assets/` 默认图 URL、`local:` 映射、仅缓存 `backgroundEnabled` 布尔值的冷启动请求门、预加载与 `<img>` 的无 Referer 策略。`<img>` 的 `object-fit:cover` / `object-position:center` 等价于上游 `div` 的 `background-size:cover` / `background-position:center`。

## 测试先红后绿

修改前，`tests/background-config-gate.test.ts` 里两条新预期在旧实现上失败：

1. `keeps the background empty with a custom hint before config and while its image loads`：旧实现配置返回后立即挂未加载图片。
2. `keeps the default visible on a first visit while a custom image loads`：旧实现配置返回后立即卸下默认图。

原测试中「配置确认即挂图片」的两处断言因此改为「预加载期间媒体未挂载，首访保留默认层/已知自定义背景再访不挂默认层」；不是削弱，而是覆盖已确认的原 bug。新增 `tests/background-media-state.test.ts` 九条状态机测试与一条过渡/无 Referer 样式契约测试，覆盖成功/失败、视频 `loadeddata`/错误、缓存过期、明暗 URL 切换、±50/0 遮罩、blur、预加载器与视频卸载清理；原配置门测试另增视频加载层及默认背景遮罩两条。成功视频解码事件在单元测试中触发，浏览器 mock 只测视频加载与 404 回退（未提供真实可播放的本地视频）。

## 本地 mock 时间线与请求清单

使用被忽略的 `work/visual-server.mjs` 临时提供 2 秒响应的 `/mock-bg-slow.webp` 与 404 的 `/mock-bg-404.webp`，配置另延迟 1–1.5 秒以观察图层。测试后该脚本会恢复原状；不进入提交。时间以导航后首个 DOM 快照为 `t≈0`，存在几十毫秒观测误差。

| 场景 | 图层时间线 | 同源服务端观测的背景请求 |
|---|---|---|
| 首访自定义慢图，配置延迟 1.5 秒 | `t0` 默认图在；`t+1.665s` 配置已确认、图片待加载，默认图仍在、媒体未挂；`t+3.630s` 媒体出现、默认层退出；全程无空白 | `t+0.029s` 默认图，`t+1.601s` 慢图 |
| 再访自定义慢图，配置延迟 1.5 秒 | `t0` 和 `t+1.644s`（待图）均无默认图/媒体；`t+3.620s` 媒体出现 | 仅 `t+1.572s` 慢图，无默认图请求 |
| 404，首访 | `t0` 默认图在；约 `t+1.4s` 失败后仍保留默认图，媒体未挂 | 默认图、404 图各一次 |
| 404，再访 | `t0` 留空；约 `t+1.13s` 404 后默认图淡入，随后可见，媒体未挂 | 先 404 图，后默认图；配置前没有默认图请求 |
| 已缓存自定义、配置实际未启用 | 配置前留空；确认后立即挂默认图 | 仅确认后请求默认图 |

额外验证：慢图预加载请求的 `Referer` 为 `null`，最终 `<img referrerpolicy="no-referrer">`；默认图请求仍是同源请求，不受这一隐私规则约束。

## 与 Komari localhost 的计算样式对照

同机浏览器、1280×720；Komari 使用 `work/komari-visual-server.mjs` 加只读参考构建（4173），本主题使用生产构建（4181/4182）。两份 mock 仅在被忽略的脚本内临时添加同样的背景场景，均未修改上游源码。

| 项 | Komari | CFSM 主题 | 结论 |
|---|---|---|---|
| 无媒体时 `html` 浅色底色、`body` | `oklch(0.935 0.015 252)`、透明 | 同值 | 一致 |
| 背景容器 | `fixed`、`z-index:-1`、`overflow:hidden`、`background-image:none` | 同值 | 一致 |
| 默认层桌面 | `cover`、`50% 100%`、`saturate(1.12) contrast(1.02)`、`scale(1.01)` | 同值；仅资产 URL 在 `/assets/` | 一致（交付路径为必要差异） |
| +50 默认背景遮罩 | `rgba(0,0,0,0.5)`、容器 opacity 1 | 同值 | 一致 |
| -50 默认背景遮罩 | 无叠层、容器 opacity 0.5 | 同值 | 一致 |
| 0 遮罩 | 无叠层、容器 opacity 1 | 同值 | 一致 |
| 自定义图片 `blur=18` | 媒体 `blur(18px)` / `transform:none` / `opacity 1` / `transition:opacity 0.8s`；内层 `background-size:cover; background-position:50% 50%` | 媒体四项同值；`img object-fit:cover; object-position:50% 50%` | 视觉等价；使用 `<img>` 保护 Referer |
| 浅色视频加载层 | 径向绿光 `rgba(16,185,129,.08)` + 灰蓝渐变；媒体 opacity 0 | 同值 | 一致 |
| 深色视频加载层 | `rgb(15,23,42)`、背景图片 none；媒体 opacity 0、`preload=auto` | 同值 | 一致 |
| 视频 404 后 | 默认层 + 回退加载层，媒体层移除 | 同值 | 一致 |

暗色默认图滤镜与 ≤768px 位置/缩放未改动，继续由既有首页视觉回归测试锁定。`data-motion='full'` 时四层与媒体的 CSS 过渡声明均为 `opacity 0.8s ease`；减弱动画时现有全局规则按预期覆盖。
