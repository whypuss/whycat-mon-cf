## 本地无头浏览器验证

用本机 Chrome 的无头模式通过 CDP 驱动本地 mock，设置与生产站点一致：卡片视图、compact 尺寸、隐藏地球、「基础」总览、开启页面动画。每帧采样卡片、页面主体、顶栏与页脚的位置、透明度和位移。

### 返回首页

**浏览器返回**（390 宽，触屏模拟）：
- 卡片仍是原来的元素，没有重新创建；
- 从第一帧起透明度为 1、没有位移；
- 滚动位置在同一帧恢复（0 或 900），刷新按钮不转动。

修改前，卡片会重新创建，并重播 460ms 的进场动画。

**页面内导航**：
- 首页主体用 150ms 淡出，期间滚动位置不变，顶栏透明度始终为 1。
- 详情页插入后才滚动到顶部，再用 300ms 淡入并上移 8px。
- 用详情页的返回按钮回到首页时，恢复原滚动位置（900），卡片是原来的元素，页脚持续显示 Live updates。

### 实时连接

首页的 `subscribe=all` 连接在「首页 → 详情 → 首页」期间保持不断。详情页的单节点连接进入时建立，离开时关闭。

### 卡片进场

- **开启页面动画**：首次打开首页时卡片依次进场。159ms 时前四张的透明度为 0.93 / 0.79 / 0.50 / 0.09，345ms 全部为 1。
- **关闭页面动画**：卡片从出现的第一帧起完全可见。

### 页脚

- 过渡期间页脚透明度与页面主体一致。
- 从首页进入详情页、详情数据延迟 4 秒仍显示骨架时，页面主体正好一屏高，页脚在第一屏之外：390 宽顶部 901 > 844，1440 宽 957 > 900。
- 首页、详情页与 404 页刚打开时，页脚均不在第一屏。

### 地球与回归

- realistic、cobe、tiled 三种地球渲染器在「首页 → 详情 → 返回」后均正常渲染，控制台无错误。
- 29 个场景的全站回归在最后一次提交后重跑，结果与 v1.1.16 一致：25 个正常，配置 500、节点列表 500、历史 500、节点 404 四个场景显示既有的错误提示。
- 在 `cb655a3` 上加跑了以下检查，结果均与 v1.1.16 一致：
  - 开启 Turnstile 的 29 个场景；
  - 验证流程 A～F，包括设置页草稿在重新验证后保留；
  - 验证组件清理与实时连接检查。

## 线上复验

生产站点以 `preview-main` 的完整提交 SHA 地址 `a3b53f2`（来源 `b296002`）安装预览，入口文件与 24 个资源都和该预览逐字节一致。站点当时已关闭全局 Turnstile，以下检查均只浏览、不做修改：

- **全站回归**：14 个线上场景全部通过，包括首页 1440 / 1440 深色 / 768 / 390、列表视图 1440 / 390、全部 6 台节点的详情页、390 宽度详情页与设置页。
- **导航组合**：手机与电脑宽度各走一遍：点卡片进详情 → 下一个节点 → 历史后退两次 → 前进 → 后退 → 进入设置页 → 后退。控制台错误、Vue 警告、失败请求均为 0。
  - 页面内点击导航播放过渡，顶栏不动。
  - 同一页面内切换节点、历史前进和后退都不播过渡。
  - 回到首页时卡片为原元素，滚动位置与网页标题正确恢复。
- **减少动态效果**：系统设置为减少动态效果时，所有导航均不播放过渡。
- **详情加载中的页脚**：点卡片 0.65 秒后详情仍显示骨架，页脚顶部位于 904（390 宽）与 960（1440 宽），均在第一屏之外。
- **真机确认**：维护者的真机录屏显示，手势返回首页已不再闪动。维护者反馈的「进入详情页先看到页脚」由 `9a43518` 与 `b296002` 修正。
