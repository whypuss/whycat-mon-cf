首页移植的第一个测试版本。

## 变更

- 延迟与丢包柱重做：柱高统一，数值由 `--signal-1..5` 五级色阶表达（延迟 ≤60 / 100 / 160 / 200 ms，丢包 ≤1 / 3 / 6 / 9%），含亮色、暗色与两套色觉友好变体；色觉友好模式叠加纹理，使等级不仅依赖颜色。
- 全局令牌调整：圆角 `--radius` 由 18px 改为 10px，字体栈改为系统字体优先，激活态改用 `--selection`。
- 控制区重排：视图切换收敛为卡片与列表两项，卡片密度归入主题设置；移除多余的排序下拉与结果计数；搜索框改为折叠式，支持清空与 ESC；高级工具开关移至控制区右侧。
- 布局调整：公告位置前移至总览与节点区之前；节点网格单列起步，640px 以上按密度 auto-fill。

## 修复

- 卡片表面改用统一的卡片规则，不再各处自定义。
- 无采样时渲染 20 根中性占位柱，替代原先的空白。

## 已知问题

- 首页 Ping 与 Loss 窗口仅能取自 `/api/servers` 的稀疏样本（约 20 点）。
- 丢包面板显示聚合值，无法区分「未配置」「超时」与「真实 0」。

## 安装

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.1
```

亦可下载本页的 `CFSM-Glassmorphism-v1.1.0-test.1.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。
