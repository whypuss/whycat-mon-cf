本版本把缺失值占位符、节点流量显示与页脚样式对齐 Komari 上游。页面结构、交互、数据接口和 Agent 上报节奏均不变。

## 更新内容

- 全站缺失值占位符统一为上游使用的短横 `-`，不再使用长破折号 `—`。
- 未设置流量上限的节点，节点卡片按上游显示真实的月度已用流量与 `∞`（例如 `4.0 GB / ∞`），不再显示为未知。已用量按 CFSM 的月度收发统计和流量计算方式得出。
- 以下两种情况，节点卡片与节点列表改为显示 `-`，不再用 `∞` 表示：
  - CFSM 关闭了流量展示；
  - 节点设有流量上限，但缺少月度统计。此时卡片仍显示该上限。
- 有公开价格但未设置到期日期的节点，第三个信息盒按上游保留两行：到期为 `-`，剩余价值为 `-`，不把未知的剩余价值推算为 `0`。
- 页脚样式按上游对齐：12px 字号、上游的次要文字色与链接字重、16px 内边距。手机宽度下两段文字各自保持完整一行并左对齐，不再拆开词组。页脚文字内容不变。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中使用稳定版构建产物标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.15
```

也可下载本页的 `CFSM-Glassmorphism-v1.1.15.zip` 手动安装，压缩包根目录仅有 `index.html` 与 `assets/`。回退到上一版可使用：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.14
```
