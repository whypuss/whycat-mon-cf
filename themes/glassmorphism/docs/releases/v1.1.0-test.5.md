基于源码审读的数据契约修正版本。

## 变更

- 完整审读 CF-Server-Monitor Worker `2.8.5 Beta5` 与探针 Agent `1.3.8` 的采集、上报、存储、REST、WebSocket 与 History 全链路，建立字段级数据契约后再据此审计实现。
- 新增 `docs/cfsm-source-audit.md`（数据链总图、端点契约、含单位与空值语义的字段契约表）与 `docs/bug-matrix.md`（逐项分类矩阵）。

## 修复

- **首页延迟与丢包柱时间轴错位**。`/api/servers` 的 `ping` 与 `loss` 为时间桶序列，固定 20 点、覆盖 2 小时、每点含全部 8 个探测目标；此前被展平为一维数组并过滤空洞，实测渲染出 68 根柱而非 20 根，任一空洞都会使后续柱整体前移。现按时间桶逐一渲染，`null` 保留为原位空洞。
- **首页缺失 `node_1`～`node_4` 探测目标**。类型与遍历仅覆盖旧四线路，导致 CFSM 2.8.5 起新增的 4 个探测点在首页从不显示，仅配置 node 探测点的节点首页探针区为空。现首页与详情页统一支持 8 个目标。
- **站点级 `show_price`、`show_expire`、`show_tf` 失效**。三项开关仅存在于 `/api/servers` 响应顶层的 `sysConfig`，而实现读取的是节点级字段（列表中恒为 `undefined`），导致运营方的隐藏设置不生效。现集合级开关下发至每台节点。
- **总览卡片单位占用主数值宽度**。`.overview-card__unit` 此前设置 `flex: none` 与 `max-width: 60%`，固定占用六成宽度；768px 实测 `455.0` 被截断为 `45…`。该单位只需省略号处理，不应预占宽度。

## 已知问题

- 窗口 20 点 / 2 小时是服务端常量，改记为平台限制；此前「视觉结构没有问题」的判断不成立，实际错位已在本版本修复。
- 面板数值本就区分三态，柱状图修复后空洞具备独立表现，相关条目关闭。

## 安装

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.5
```

亦可下载本页的 `CFSM-Glassmorphism-v1.1.0-test.5.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。
