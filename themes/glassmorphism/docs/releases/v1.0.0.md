首个正式版本。将 Komari Glassmorphism 的界面与交互移植到 CF-Server-Monitor 的公开主题 API 之上。

## 新增

- 首页仪表盘、卡片与列表两种导航、详情页层级、响应式断点、动效与图标以 Komari Glassmorphism 的界面为蓝本，保留 `globe.gl` + `three`、`cobe`、tiled map 三套 Earth 渲染器。
- 接入 CFSM REST、多 apiBase 归属、WebSocket 增量更新与重连、单节点详情订阅；History 图表基于 ECharts。
- 支持 CT / CU / CM / BD 与 Node 1～4 的 Ping 与 Loss，全链路保持 `false`、`null`、数值三态。
- 主题设置采用默认值、后端 `theme_options`、本地覆盖三层模型；后端保存仅使用 `POST /api/theme_options`，支持 JWT 与 Turnstile。

## 已知问题

- 公开主题 API 不提供真实 IP、ASN、城市与精确坐标，Earth 仅做国家与地区级定位。
- 管理功能由 CFSM 的 `/admin#admin` 提供，主题内不重复实现。

## 验证

已覆盖空数据、部分数据源失败、全部离线、401 / 403 / 409 / 5xx、稠密节点、主题切换、渲染器切换、减少动画，以及六档浏览器视口。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」填入滚动分支，随最新稳定版更新：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-dist
```

固定在本版本请使用不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.0.0
```

亦可下载本页的 `CFSM-Glassmorphism-v1.0.0.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。
