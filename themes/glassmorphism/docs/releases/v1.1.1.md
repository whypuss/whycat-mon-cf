自 v1.1.0 以来的正式版，包含第二阶段三轮测试与发布前收口的全部内容：详情页负载区与延迟区重建、主题设置页重建、首页延迟与丢包改用窗口平均口径、节点卡四档盒模型与预设表面色修正，以及详情页链接的清理。

## 新增

- 详情页负载区与延迟区重建：时间范围选择、图表卡栅格（CPU 与负载、内存与 Swap、磁盘、实时网络、网络连接、进程，GPU 与磁盘 IO 在有数据时显示）、探测目标卡（平均延迟、丢包率、波动率与统计详情）、全选与全不选、延迟大图。
- 厂商识别：详情页顶栏的厂商标识与系统信息中的「厂商」一格，依据节点名称、分组、地区、标签以及约定的 `asn` / `org` 标签，不查询 IP。标签约定见 `docs/provider-tags.md`。
- 详情页负载图的磁盘耗尽预测：按历史中的磁盘用量趋势估算写满时间，预计天数低于预警阈值时以预警色提示；复用该图已取回的历史，不额外请求。
- 设置页新增「数据更新间隔」「启用磁盘耗尽预测」「磁盘预测预警天数」「详情页分区标签页」四项控件。
- 历史数据新增进程数与 TCP / UDP 连接数。

## 变更

- 主题设置页改为 8 个分组呈现 46 个控件，分组标题与顺序随之调整；顶栏与首页、详情页统一。
- 首页与列表的延迟、丢包由最近一次采样改为**窗口平均**（取自 `/api/servers` 已返回的最近 2 小时、最多 20 个真实采样）；站点关闭三网详情时回落到最新一次上报并在提示中写明口径。
- 节点卡舒适与宽松两档补齐盒模型（头部 44 / 52、主体内边距 `0 16 16` / `0 24 24`、内容行距 12 / 16、延迟面板 48 / 56）。
- 节点卡的预设表面色改用固定的配色取值，并与应用界面的表面变量分离；预设不再整表覆盖全局 `--glass*`。
- 延迟图的「平滑峰值」改称「曲线平滑」：它只改变折线曲率，不改写、不过滤、不插值任何采样值。
- 详情页链接在单后端站点上不再带 `?source=`，统一由一处生成；旧的带该参数的链接仍可打开，进入后以替换当前历史记录的方式规范化，其余查询参数保留。多 `apiBase` 部署仍保留节点归属所需的来源信息。
- 「数据更新间隔」驱动 WebSocket 不可用时的 REST 回退刷新间隔，下限 5 秒；服务端推送节奏由 CFSM 决定。
- CFSM 公开接口未提供的「RPC 连接模式」与「显示访客信息」不再出现在设置页；两项仍保留在保存快照中以兼容旧配置。

## 修复

- 节点卡「剩余 N 天」在行边缘被裁切。
- 迷你尺寸节点卡的 CPU、内存标签被截断为「C...」「内.」。
- 节点卡的进度条、标签、提示行、网速与流量百分比配色错误。
- 离线节点卡的遮罩超出内容区并遮住卡片头部；离线卡带有多余的红色描边。
- 详情页信息卡高度多出 2px。
- 舒适档高出 4px、宽松档矮 36px；宽松档的面板高度规则因类名不匹配长期未生效。
- 配色预设此前整表覆盖全局表面变量，导致预设差异扩散到提示框、面板与弹层等不应受影响的界面。
- 设置页此前只呈现 44 项设置且分组方式不合适；「数据更新间隔」「磁盘耗尽预测」等项此前没有实际行为。

## 已知限制

以下各项在本版本中**仍然存在**，不宣称已解决：

- **延迟图的极高值**：「曲线平滑」只改变折线曲率，不重写、不过滤、不插值任何采样值，因此个别尖峰仍会压缩常态区间的可读性。
- **配色预设的表面色**：本版本只把节点卡接入配色预设；顶栏与顶部统计卡仍使用本主题自己的取值。
- **真实环境未覆盖的边界场景**：验收站点的节点未出现超长节点名、超长系统名、无价格 / 免费、已过期、无探测目标、离线节点与稀疏字段等情形，这些场景只有本地构造样本的覆盖。
- **多 `apiBase` 缺少实机证据**：验收站点为单后端，多来源部署下必须保留 `?source=` 的分支只有单元测试与本地覆盖，没有真实环境验证。
- **磁盘预警色的视觉验证缺口**：预警色规则与类绑定有源码级断言与单元测试，但在无头 / 隐藏浏览器面板环境下无法读到可靠的计算颜色，未完成视觉实测。
- 负载区没有「实时」与「自定义」时间范围，CFSM 未提供对应接口；磁盘耗尽预测需要将时间范围选到 2 天以上，未登录时历史最长 24 小时。

## 验证

- 代码检查、类型检查、单元测试（356 项）、构建与产物校验均已通过。
- 真实部署（Worker `2.8.5 Beta5`，5 台真实节点）分两次验收：节点卡四档几何在 1440 与 375 下逐项实测、无横向溢出、无文本截断；详情页链接的六条路径（首页点击、上一个 / 下一个连续切换、无 `source` 深链接直开与刷新、旧链接兼容、前进 / 后退、名称与接口数据对应）逐项通过，旧链接规范化未增加历史记录、未产生重复请求。
- 视觉核对在 1440 与 375 的本地环境下进行；真实部署的对照限于本主题自身的前后行为。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.1
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.1.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退入口：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0
```
