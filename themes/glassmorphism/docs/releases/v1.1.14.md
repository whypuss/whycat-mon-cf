本版仅修复首页节点卡片第三个信息盒的显示分支，不改变其它布局、交互、数据接口或 Agent 上报节奏。

## 更新内容

- 有公开可见的有效正价格、但缺少可显示的到期日期时，第三个信息盒显示单行 `—`，不再重复显示 CPU 指标下方已有的 1/5/15 分钟负载。
- CFSM 隐藏到期日期时，同样只显示占位，不泄露到期状态，也不把未知剩余价值推算为 `0`。
- 有真实可显示到期日期的节点，以及免费、无价或价格不可公开显示的节点，保持原有显示行为。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中使用稳定版构建产物标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.14
```

也可下载本页的 `CFSM-Glassmorphism-v1.1.14.zip` 手动安装；压缩包根目录仅有 `index.html` 与 `assets/`。回退到上一版可使用：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.13
```
