本版本按 Komari 上游对齐首页的保留方式与换页过渡，并修正页脚在内容较短时的位置。数据接口、实时连接协议与 Agent 上报节奏均不变。

## 修复

- 从详情页返回首页时，首页不再重新创建：
  - 卡片不再重新播放进场动画。在手机上用手势返回时，也不会与浏览器自带的返回画面叠加而闪动。
  - 不再重新读取数据，不再重建实时连接，停留的位置保持不变。
- 关闭页面动画时，首页卡片直接完整显示，不再逐张出现。
- 进入详情页后数据仍在加载时，页脚不再先于内容出现在第一屏。页脚与上游一样始终位于第一屏之后。

## 变更

- 页面内的点击导航采用与 Komari 一致的换页过渡：旧页面淡出，新页面淡入并轻微上移。涉及进入详情页、进入主题设置页，以及详情页左上角的返回按钮。
  - 顶栏在过渡期间保持不动，页脚随页面内容一起淡入淡出。
  - 浏览器的历史导航直接显示目标页，衔接浏览器自带的返回动画，包括手势返回、返回键与前进。
  - 关闭页面动画，或系统设置为减少动态效果时，不播放换页过渡。
- 详情页左上角的返回按钮回到离开首页时的位置，此前回到页面顶部。
- 首页卡片的进场效果改为与上游一致的列表过渡：首次打开首页时依次进场，每张间隔 35ms。
- 浏览详情页期间保留首页的实时连接，返回首页后数据仍是实时更新的；详情页的连接照旧在离开时关闭。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中使用稳定版构建产物标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.17
```

也可下载本页的 `CFSM-Glassmorphism-v1.1.17.zip` 手动安装，压缩包根目录仅有 `index.html` 与 `assets/`。回退到上一版可使用：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.16
```
