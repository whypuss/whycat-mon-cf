首页总览卡片、文本格式与默认背景的对标版本。

## 变更

- 总览卡片内容改为两段式：内存与硬盘显示「已用数值 + `GB / 总量 GB`」而非百分比；系统分布显示占比最高的系统名与台数；预设内容与顺序逐项取自 `GENERAL_CARD_PRESETS` 与 `ALL_GENERAL_CARD_KEYS`。
- 首页文本格式统一：字节采用 KB / MB / GB / TB / PB（换算基数仍为 1024），精度依次为 0 / 0 / 1 / 1 / 2 位；运行时长芯片改为「在线 N 天」；计费周期本地化为月、季、半年、年、两年、三年、四年、五年。该组格式仅服务首页，详情页格式保持冻结。
- 快捷控制「完整」预设由八项收敛为六项（收藏、总流量、峰值、离线、高负载、即将到期）；自定义模式仍可选择上行与下行。
- 未配置自定义背景时改用主题自带的默认背景图（32436 字节），作为源码资源打包进 `assets/`，主题包根目录仍仅含 `index.html` 与 `assets/`。

## 修复

- 总览卡片表面修正：它不应套用节点卡片那条 `!important` 规则，此前照搬导致表面错误。
- 节点卡片改用默认玻璃预设的实际取值：边框 `rgba(203,213,225,.6)`、圆角 14px。
- 球体版前六张卡片改为按列排布，使用显式栅格定位。
- tiled 渲染器的卡片跨度、行高、间距、内边距与地图高度整体重排。
- 移除窄屏自定义的间距与字号覆盖，总览卡片在所有断点统一为 8px 间距与 12px 内边距。

## 验证

首页审计终态 P0 = 0、P1 = 0、FAIL = 0；21 个测试文件、183 个测试全部通过。

## 安装

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.3
```

亦可下载本页的 `CFSM-Glassmorphism-v1.1.0-test.3.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。
