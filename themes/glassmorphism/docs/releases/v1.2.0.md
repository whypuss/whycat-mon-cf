本版本补齐 Komari 上游的五张总览卡片，首页公告支持受限 Markdown，并将卡片切换动效、总览统计口径与访客提示文案对齐上游；同时修复 Turnstile 验证、详情页负载图与数值格式等问题。数据接口、实时连接协议与 Agent 上报节奏均不变。

## 新增

- 首页总览新增「上行最高」「下行最高」「连接峰值」「GPU 峰值」「流量配额」五张卡片，计算方式与 Komari 上游一致：
  - 前四张取在线节点中该项数值最高的一台；没有该项数据的节点不参与比较，不按 0 计算。
  - 「流量配额」汇总已设置流量上限的节点。站点隐藏流量的节点不计入；缺少当月流量的节点列在提示中，不按 0 计入；没有节点设置上限时显示「-」与「无限流量」。
  - 「财务」「流量」「GPU」卡片方案恢复上游的第六张卡片，「完整」方案按上游顺序列出全部 30 张。上游的「虚拟化分布」依赖 CFSM 未提供的字段，暂不提供。
- 首页公告支持与上游相同的 Markdown 子集：粗体、斜体、行内代码、链接、图片与换行。
  - 链接仅支持 http(s)、mailto、tel 与站内路径，图片仅支持 http(s)、data 与站内路径；不符合的链接不可点击，图片不加载。
  - 标题、列表等其它语法按原文显示；公告中的 HTML 也按原文显示，不会被执行。

## 变更

- 首页公告的样式与上游提示框一致，去掉图标与默认标题「站点公告」，标题改为可选。只填写标题、未填写内容时，不再显示公告。
- 卡片切换动效与上游一致：
  - 卡片视图：切换分组时旧卡片立即移除，新卡片依次进场；使用快捷筛选时旧卡片淡出，新卡片依次进场；实时数据改变排序时，卡片平滑换位。
  - 列表视图：首次显示与切换分组时逐行进场；使用快捷筛选时，离开的行淡出，其余行平滑移到新位置。节点超过 30 个或关闭页面动画时不播放。
- 总览卡片的统计口径与上游一致：
  - 「高负载节点」不再统计离线节点，对应的快捷筛选同步调整。
  - 内存、硬盘与 Swap 只汇总同时上报已用量与总量的节点，缺失的一侧不再按 0 计入。
  - 「即将到期」包含已过期节点、不含免费节点，阈值最小为 1 天。
  - 「实时峰值」按上行与下行速率之和计算，「平均 GPU」按节点平均。
  - 平均 GPU、GPU 节点、离线、高负载、即将到期与流量预警的提示按上游格式列出节点；未填写币种的价格显示为「未标明币种」。
- 快捷筛选的计数只统计当前分组与搜索结果内的节点；「总流量」「上行」「下行」「峰值」等排序按钮显示该范围内的节点数，此前固定显示 0。
- 列表视图的厂商标识与详情页使用相同的识别规则与图标。
- 访客可见的错误、离线与连接提示改用中文说明发生了什么、该怎么做，不再显示 CFSM 错误代码、英文原文或接口路径：
  - 401、409、503 等状态仍明确说明，HTTP 状态码单独一行显示。
  - 首页数据源加载失败时显示简短原因，例如「服务器出错（HTTP 500）」「连接超时」「需要人机验证」。
  - 所有节点都离线时，提示说明当前显示的是各节点离线前最后一次上报的数据。
  - 实时连接超时、暂停与回退刷新的提示改用通俗表述，回退提示写明实际刷新间隔。
  - 主题设置的保存提示不再出现 JWT、theme_options 等术语。
- 顶栏刷新按钮与在线状态的提示文字改为「刷新数据」「节点在线状态」。

## 修复

- 开启 Turnstile 的站点：
  - 通过人机验证后，偶尔仍被判定为失败、需要再验证一次。
  - 验证通过后，首页会先短暂显示空列表再出现数据；现在等数据加载完成后才关闭验证界面。
- 停留在详情页或主题设置页时，若站点标题发生变化，浏览器标签标题不再被首页标题覆盖。
- 小于 1 字节的数值不再显示为「512.00 PB」这类错误单位。
- 详情页负载图：
  - 「实时」档位的时间轴与提示按实时窗口格式显示；先选 1 天及以上范围再切到「实时」时，不再显示日期、丢失秒数。
  - 未登录访客选择超过 24 小时的范围（CFSM 返回 401）后再切到「实时」，实时数据不再被 401 提示遮挡。
- 首页高级工具（开启「登录后显示高级工具」且已登录时显示）：
  - 健康摘要将离线节点只记为离线，不再用其最后一次上报的 CPU、内存、硬盘、负载等指标评分；存在严重问题时，优先于「数据不足」显示。
  - 性价比对比的月价与详情页一致，按价格与付费周期折算为 30 天；「$」与「USD」等写法归入同一币种；未设置价格的节点不再计为免费。
- 主题设置：磁盘预测预警天数超出 1–3650 的整数范围时，保存前即提示错误；此前保存会静默保留旧值。
- 图表悬浮提示中的名称统一按纯文本显示。

## 已知问题

- 主题使用 `oklch()`、`color-mix()` 与 `:has()` 等 CSS 特性，需要 Chrome / Edge 111、Safari 16.2、Firefox 121 或更新版本；更早的浏览器可能出现配色或排版异常。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中使用稳定版构建产物标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.2.0
```

也可下载本页的 `CFSM-Glassmorphism-v1.2.0.zip` 手动安装，压缩包根目录仅有 `index.html` 与 `assets/`。回退到上一版可使用：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.17
```
