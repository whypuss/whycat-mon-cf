本版本收口六轮已审计通过的冷启动、背景层与并发更新修复。主题沿用 CFSM 的公开接口与 Agent 上报节奏；没有新增虚构数据，也没有改变实时采样或尖峰规则。

## 更新内容

### 冷启动与首屏

- 冷启动先等待主站点配置确定，再渲染依赖设置的首页、详情页和设置区域；配置失败仍会解除等待并显示原有错误态。多后端详情页同时等待主配置与节点所属来源的配置，不会先闪其他来源的展示设置。
- 暂存上次确认的明暗模式和自定义背景开关用于冷启动首帧，后端配置返回后仍以真实配置和浏览器覆盖为准；不缓存背景 URL，也不改变三层设置模型。
- 顶栏首次渲染直接使用 CFSM 注入 HTML 的真实站点名，并在首次渲染时解析站点图标，不再先显示默认名称或占位后跳变。
- 按上游移植冷启动全屏加载遮罩：每次应用冷启动仅出现一次，覆盖顶栏；等待期间不渲染页面主体，完成后淡出。同一次访问中的站内切页或页面内刷新不重复显示遮罩。
- 应用启动即发起主 `/api/config`，首页和详情页入口同时发起 `/api/servers`；页面复用在途请求，同一端点不重复请求。设置页入口不额外请求节点列表。

### 背景与按需加载

- 背景层按 Komari 上游行为复刻/移植：新图片预加载成功后淡入，加载失败回退默认图；视频保留加载层，模糊与遮罩遵循上游语义。
- 全站仅在应用根挂载一次背景层，页面切换不重复创建。隐藏地球时不再下载地球渲染模块。

### 数据与并发安全

- 首页累计流量只合计数据完整的节点；数据不完整的节点不被当作 0，提示文字说明合计范围。
- REST 节点列表刷新期间收到的 WebSocket 推送会按顺序重放到新快照，避免较新的实时数据被较慢的 REST 响应覆盖。
- 设置保存并发时给出明确提示，避免把正在进行的保存误当作另一笔已完成写入。
- 修复 Windows 环境下的打包测试，使产物结构校验与实际构建路径一致。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中使用稳定版构建产物标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.13
```

也可下载本页的 `CFSM-Glassmorphism-v1.1.13.zip` 手动安装；压缩包根目录仅有 `index.html` 与 `assets/`。回退到上一版可使用：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.12
```

<summary><b>安装缓存与已知边界</b></summary>

- CFSM 会按主题地址从 GitHub 拉取并分别缓存页面及资源：分支/标签地址约 1 小时，完整提交 SHA 地址约 1 天。重新应用同一地址不会清空缓存。
- `theme-dist` 和 `preview-main` 是滚动分支，更新后最长约 1 小时内可能出现新旧文件混用导致空白；稳定版推荐固定 `theme-v1.1.13`，预览版推荐固定 `preview-main` 当前构建提交的完整 SHA。
- Agent 配置的 WSS 上报间隔、probe 的 `false / null / 0 / number` 语义、History 真实缺口和隐藏尖峰规则保持不变。
