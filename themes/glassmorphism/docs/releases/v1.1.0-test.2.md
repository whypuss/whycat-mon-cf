针对隐藏 Earth 与手机端节点卡片的修复版本。

## 变更

- 补齐 `tabler:calendar-stats` 与 `tabler:coins` 两个缺失图标，仍在构建期内联，运行时不访问外部 CDN。

## 修复

- 隐藏 Earth 时，总览卡片改用 3 / 6 列独立网格，消除卡片宽度异常与右侧留白。
- 手机端节点卡片底部保持三列，速率、流量、到期与金额各自具备独立的窄屏省略层。
- 第三列不再输出完整 ISO 日期，改为「剩余 N 天」「已过期」「长期」「—」。

## 验证

375 / 430 / 768 / 1024 / 1440 / 1920 六档视口均无页面级横向溢出；数据与协议层、Ping 柱、Earth 渲染器、节点点击路径与详情页结构均未改动。

## 安装

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.2
```

亦可下载本页的 `CFSM-Glassmorphism-v1.1.0-test.2.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。
