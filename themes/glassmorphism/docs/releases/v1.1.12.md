本版本集中修复站点标题冷启动、多数据源归属、REST / WebSocket 并发、History 切换与主题设置保存中的 17 个可复现问题。页面结构、功能入口、视觉样式与 Agent 配置的 WSS 上报节奏均保持不变。

## 更新内容

### 修正冷启动与站点标题闪烁

- 配置尚未返回时，Header 使用固定尺寸占位，不再先闪默认站点名或错误首字；真实标题到达后一次切换完成。
- 详情页冷启动时配置、节点、列表与历史并发加载，不再让慢配置串行阻塞主要内容。
- 多数据源详情严格使用节点所属来源的标题、版本、授权状态与展示开关，不会短暂借用主来源数据。
- favicon 加载失败、来源切换和配置明确失败时都有稳定、可解释的回退状态。

### 收敛 REST、WebSocket 与 History 竞态

- HTTP 超时和调用方取消覆盖完整响应体读取阶段，详情卸载后迟到请求不会访问已释放状态。
- 配置、节点列表与主题保存请求复用各自的 in-flight Promise，并用 revision 阻止旧请求覆盖新状态。
- 慢 REST 补偿不会回滚请求期间已经到达的较新 WebSocket 指标。
- 首页与详情在快速切换前后台时会等待同一次刷新，再按当前可见性恢复连接，不再丢失重连请求。
- WebSocket 订阅帧、heartbeat 或 error 路径异常时统一关闭旧连接，避免残留连接与重复更新。
- 切换 History 时间范围时不再把旧区间显示在新标签下；同范围刷新失败会保留最后一份真实快照。

### 保持数据真实性与保存幂等

- 流量 SUM / MAX 缺少任一方向时保持未知，不再把缺失方向补成 0，也不会据此产生错误排序或百分比。
- Probe 名称等待所属来源配置，不再先闪默认线路名；`false / null / 0 / number` 三态语义不变。
- 快速重复点击主题保存会合并为一次写入和一次配置回读。
- 没有改变 REST、WebSocket、History、probe、多 API Base、JWT / Turnstile 或 `theme_options` wire 契约。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.12
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.12.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退到上一版：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.11
```
