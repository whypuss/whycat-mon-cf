详情页与实例详情的移植版本。

## 变更

- 详情指标卡改为数值与单位两段式（`USD18` + `/ 年`、`31` + `天`、`2.0` + `MB/s`），高度与字号按 `min-h-10 md:min-h-18`、`text-base sm:text-2xl` 设定；预设内容与顺序逐项取自 `DETAIL_METRIC_CARD_PRESETS`。
- 新增「剩余价值」卡，为「财务」预设的第四张；月均支出改为「金额 / 月」，计费周期未知时显示「不适用」而非隐藏整卡；剩余时间改用统一文案，并按 5 / 10 / 36500 天阈值着色。
- 四张信息卡补充内容：硬件信息新增 CPU 全宽块与 PassMark「CPU Mark 排行」外链；系统信息补充 OS 图标与逐项图标；存储信息补齐文案与图标；网络信息补充配额进度背景，按使用率三档着色。
- 实现 `nodeDetailSectionTabsEnabled` 分区 Tab，此前该设置项无任何实现。
- 顶部工具条与历史范围选择器改为半透明底色的药丸组形态。

## 修复

- 指标卡与信息卡表面修正：详情卡应为 `--background` 的 50% 且无边框，此前沿用了节点卡片的样式。探针卡、GPU 卡、磁盘 IO 卡、历史图表卡与历史空态、错误态一并统一。
- 移除详情指标卡的进度条，该元素属于多余绘制。
- 详情页与首页共用同一套字节与价格规则，`formatHome*` 相应更名为 `formatDisplay*`；运行时长为两页唯一差异，各自独立实现。
- Windows 环境下 `bun run typecheck` 不会实际检查 SFC 模板，此前因此掩盖了一处模板类型错误；现改用仓库外的便携 Node 复跑。

## 安装

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.4
```

亦可下载本页的 `CFSM-Glassmorphism-v1.1.0-test.4.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。
