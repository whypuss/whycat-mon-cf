顶部区域的专项修复：统计卡的数值与单位重新落回同一条基线，滚动后的站点顶栏恢复应有的通透。其余功能与 v1.1.1 相同。

## 更新内容

- **统计卡的单位不再浮在数值上方**。此前单位与「已用 / 总量」说明与主数值贴死并抬高了一截。1440 实测：单位基线由高出 9px 归零，两段文字间距由 0 恢复为 4px。
- **滚动后的顶栏恢复通透**。此前会压上一层近乎不透明的底色与一道投影，页面像被切成两段；现在只保留模糊与一条细分隔线，内容从顶栏后面透出来。顶栏高度、内容宽度、图标与按钮位置一律未动，首页、详情页、设置页共用同一套。
- **统计卡图标配色固定**。常态与悬浮改用固定的中性蓝灰，不再随主题的次要文字色变化。
- **设置页文案收敛为一句一事**：开头交代设置项数量与保存时机；配色方案标明作用范围；不生效的设置直接点出缺少哪个服务端字段。

## 一处旧结论的更正

v1.1.1 曾把「顶栏与顶部统计卡尚未接入配色方案」列为遗留项。逐项复核后，这一条从前提上就不成立：这两处按设计不由配色方案驱动，而顶部统计卡的表面处理本就是正确取值。配色方案的职责仅限节点卡这一组变量。该项自本版本起撤下。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.2
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.2.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退到上一版：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.1
```

- **延迟图对极高值的处理**：「曲线平滑」只改变折线曲率，不重写、不过滤、不插值任何采样值，因此个别尖峰仍会压扁常态区间。这是保留真实采样的取舍。

- **移动端触屏未实测**：统计卡在窄屏下会截断，完整值由提示气泡承担。气泡在真实触屏设备上如何唤出没有实机证据，模拟器派发的仍是鼠标事件。
- **部分边界场景只有本地构造样本覆盖**：超长节点名、超长系统名、免费 / 无价格、已过期、无探测目标、离线节点、字段稀疏的节点等。
- **多后端部署缺少实机验证**：验收站点是单后端，多来源的分支只有单元测试与本地覆盖。

<details>
<summary><b>验证与技术细节</b></summary>

**单位偏移的成因**：数值行的布局类写在提示组件上，而提示组件的根节点只渲染插槽，这个类落不到任何元素，排版退回提示组件自带的 `inline-flex`，基线与间距一并失效。现在数值行是提示组件内部的独立容器，有提示与无提示两条分支共用同一套结构与类名。

**顶栏的具体取值**：此前是约 77% 不透明度的底色 + `blur(20px) saturate(155%)` + 投影；现在是 `blur(16px)` + 一条低透明度分隔线，底色全透。

**质量门**：代码检查、类型检查、单元测试（364 项）、构建与产物校验均已通过。新增的数值行回归用例以服务端渲染断言真实 DOM，而不是断言源码里出现过某条样式；单独回退这次的属性透传修复，该文件 8 项里立刻倒下 4 项。

**本地对照**：同一台机器、同一浏览器、同一视口与同一组展示数据，覆盖 375 / 767 / 768 / 1440 / 1920 五个宽度、明暗两套主题、四种内置配色方案与自定义配色、地球关闭 / 球体 / 平铺三种顶部布局。

**真实部署验收**（Worker `2.8.5 Beta5`，5 台真实节点）：线上入口资源与候选产物逐字节相同，22 个资源全部可达；五张统计卡在 1440 浅色、1440 深色与 375 下均为基线差 0、间距 4px；顶栏三态在首页、详情页、设置页取值一致；悬浮与移出的表面切换、提示气泡的完整值均正常。检查过程为只读，未修改站点的主题配置。

</details>
