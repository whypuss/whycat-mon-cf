顶栏左上角改为显示站点自己的图标。其余功能与 v1.1.5 相同。

## 更新内容

**顶栏现在显示你的站点图标**，与浏览器标签页上的那张一致。

这个位置此前是一枚固定的装饰图形（翡翠圆环套蓝点），画在代码里，跟谁的站点都一样，也不随配色方案变化。现在它会读取你在 CFSM 后台「设置 → 外观」里填的「网站图标」。

没设置过也不用管：CFSM 自带一张默认图标会顶上；再取不到就显示站点名首字。这个位置不会出现空白。

圆形边框、毛玻璃底与尺寸都没变，图标按比例裁进这个圆。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.6
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.6.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退到上一版：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.5
```

<summary><b>已知限制</b>（本版本未解决，如实列出）</summary>

- **详情页会多取一次节点列表**：价格 / 到期 / 流量这三个站点级开关只出现在节点列表接口里，详情接口不返回，因此需要单独取一次。该请求带守卫，只在直接打开或刷新详情页时发生一次。
- **首页每次手动刷新会发两个请求**：站点配置与节点列表各一次。不会并发重复，但每次刷新都是两个。
- **隐藏总览卡片但保留地球时，宽屏左侧会留白**：这个布局把地球放在右半边，卡片本占左半边。不会溢出或遮挡，窄屏不受影响。
- **延迟图对极高值的处理**：「曲线平滑」只改变折线曲率，不重写、不过滤、不插值任何采样值，因此个别尖峰仍会压扁常态区间。这是保留真实采样的取舍。
- **对话框输入框与描边按钮不随配色方案变化**。
- **移动端触屏未实测**：提示气泡在真实触屏设备上如何唤出，没有实机证据，模拟器派发的仍是鼠标事件。
- **部分边界场景只有本地构造样本覆盖**：超长节点名、免费 / 无价格、已过期、无探测目标、字段稀疏的节点等。
- **多后端部署缺少实机验证**：验收站点是单后端，多来源的分支只有单元测试与本地覆盖。

<summary><b>验证与技术细节</b></summary>

**图标的取值顺序**，三级回退，任何一级都不会让这个位置空着：

1. **站点图标**。CFSM 把后台设置的图标作为 `<link rel="icon">` 注入页面，值通常是 data URI；站点配置接口不返回这个字段，因此从页面上已有的那一条读取。未设置时该注入不存在，退到 `/favicon.ico`，CFSM 自带一张默认图标会在此响应。
2. **站点名首字**。图标缺失或加载失败时启用。
3. **原有的几何标记**。站点名也为空时才出现。

**质量门**：代码检查、类型检查、单元测试（399 项）、构建与产物校验均已通过。新增用例覆盖三级回退的每一级、服务端渲染下的取值守卫，以及图标加载失败时的降级；其中一条专门锁住「几何标记不得再挂在容器的 `::before` 与后代 `span` 上」——留在原处的话，站点图标显示时它们会画在图标底下。

**真实部署验收**：线上 23 个资源全部可达且与候选产物逐字节相同，入口引用与候选包内一致。顶栏实测渲染为站点图标，原生尺寸 256×256、按 30×30 呈现并裁剪进圆形容器，容器伪元素的 `content` 为 `none`（确认旧标记已不参与绘制）；深色与 375 窄屏下同样正常，无横向溢出。

**回归项未受影响**：详情页冷启动仍为 4 个请求，延迟图无取样提示，两行控件取值不变，两类图默认同为 1 小时；首页、设置页、详情页在深色与窄屏下全程无控制台报错。

检查过程为只读，视口与配色方案只用浏览器本地模拟并已复位，未修改站点的主题配置。

</details>
