第二阶段第一个测试版：验收已部署的 v1.1.0，并修复图表逐序列配色与节点卡字体盒模型。

## 变更

- 详情页历史图表改为**逐序列**配色：内联图改用按语义分配的角色调色板，而不是通用的 8 色序列板。内存 RAM 由 `#4ECDC4` 改为 `#FF6B6B`、Swap 改为 `#FFB347`、磁盘改为 `#4ECDC4`、网络下载 / 上传改为 `#60A5FA` / `#A78BFA`、GPU 首条改为 `#34D399`。
- 渐变填充只加在 CPU、RAM、磁盘已用三条序列上，**网络图两条线不加填充**——上一版把内联图一概描述为「带渐变填充」并不准确。
- 线宽按图表族区分：内联图 1.5px + 圆线帽，独立指标图 1.6px 无线帽。

## 修复

- **节点卡内部行高偏小、再由卡片内边距抵消**。逐行实测后成组修正：12px 文本行高补为 16px、11px 提示补为 15.7143px、标签高补为 20px；卡片盒模型改为卡片 padding 0、头部 `12px 16px`、主体 `0 16px 16px`，探针面板改为 padding 8px / gap 6px / 柱区 11px。指标网格由 92 → 97.44，标签行 18.5 → 20，头部 24 → 44，内容宽 273 → 269，卡片总高由 333.75 改善为 **331.69**。375 / 768 / 1440 三档复测，卡片坐标与宽度、总览卡片几何、页面无横向溢出均未变化。

## 已知问题

- **CHART-003（悬浮曲线消失）仍未复现**：本轮用真实指针在 1440 与深浅两种主题下悬浮、移出、图例隐藏与恢复，曲线均正常绘制。可复现的相关事实是 tooltip 为 `confine: true`，气泡被限制在图表框内、会遮住部分绘图区（1440 约 11%、375 约 21%）。移动端真实触摸尚未覆盖。
- 延迟 / 丢包面板主数值仍显示最新上报值，是否改为窗口平均尚未裁决；数据来源已复核正确，但口径歧义未消除。
- 探针首轮空串转 0、`node_1..4` 长窗口聚合两项仍缺实机证据。
- `comfortable` / `large` 两档节点卡与详情页其余组件的行高尚未统一。

## 安装

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.1-test.1
```

亦可下载本页的 `CFSM-Glassmorphism-v1.1.1-test.1.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。
