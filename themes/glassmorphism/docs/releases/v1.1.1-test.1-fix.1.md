修复节点卡「剩余 N 天」被截断的显示问题。基于 `v1.1.1-test.1` 的实际应用反馈。

## 修复

- **节点卡第三个盒子的「剩余 N 天」被切在字形中间**。该盒子两行之间的间距应为 2px，本主题三个盒子统一用了 4px，三个间隙多占 6px。303px 卡片下该行可用宽度仅 74px，实测「剩余 662 天」需 75.36px、「剩余 1653 天」需 81.81px，而行内四个 `span` 均为 `flex: 0 0 auto` 且无省略号，超出部分被直接裁掉。改为 2px 后，三位数天数需 69.36px，可完整显示。
- 该行与「剩余价值」行补挂原生 `title`，携带完整文本。

## 已知问题

- 四位数天数（如「剩余 1655 天」）在 303px 卡片下仍需 75.81px，超出可用宽度约 1.8px，完整值可通过悬停 `title` 读取。若要在卡面上完整显示，需要调整第三个盒子的列宽或字号，会改变既定的卡片版式，留待裁决。
- `v1.1.1-test.1` 的其余已知问题不变：CHART-003 未复现、D-01 口径未裁决、两项 NEEDS-EVIDENCE 待隔离环境验证、`comfortable` / `large` 档节点卡行高未统一。

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.1-test.1-fix.1
```
