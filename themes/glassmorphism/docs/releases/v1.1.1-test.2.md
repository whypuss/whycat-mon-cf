详情页重建负载区与延迟区，新增厂商显示，并修正首页节点卡的若干显示偏差。基于 `v1.1.1-test.1-fix.1` 的实际应用反馈。

## 新增

- 详情页负载区：时间范围选择与图表卡片栅格，包括 CPU 与负载、内存与 Swap、磁盘、实时网络、网络连接、进程；GPU 与磁盘 IO 在有数据时显示。
- 详情页延迟区：独立的时间范围、全选与全不选、探测目标卡片（平均延迟、丢包率、波动率及统计详情）、平滑峰值开关与延迟大图。
- 厂商：详情页顶栏的厂商标识与系统信息中的「厂商」一格。依据节点名称、分组、地区、标签及约定的 `asn` / `org` 标签识别，不查询 IP。标签约定见 `docs/provider-tags.md`。
- 历史数据新增进程数与 TCP / UDP 连接数。

## 变更

- 图表方案默认包含连接数与进程；自定义模板可使用中文名称。
- 移除详情页原有的 PROBES、DISK IO、GPU、HISTORY 四个分区，相应内容并入负载区与延迟区。
- 系统信息第四格由「数据源」改为「厂商」，数据源名称保留在该格的悬停提示中。
- 正文与次要文字改用基础文字色；配色预设的文字色仅作用于节点卡。

## 修复

- 节点卡「剩余 N 天」在行边缘被裁切。
- 迷你尺寸节点卡的 CPU、内存标签被截断为「C...」「内.」。
- 节点卡的进度条、标签、提示行、网速与流量百分比配色错误。
- 离线节点卡的遮罩超出内容区并遮住卡片头部；离线卡带有多余的红色描边。
- 详情页信息卡高度多出 2px。

## 已知问题

- 首页丢包显示最近一次采样，是否改为窗口加权平均待定。
- 配色预设的表面色仍使用本主题自己的取值。
- 负载区没有「实时」与「自定义」时间范围，CFSM 未提供对应接口。
- 延迟统计基于所选时段的历史采样计算，长时段数据为服务端聚合后的值。

## 验证

- 代码检查、类型检查、单元测试（314 项）、构建与产物校验均已通过。
- 在 1440×900 的浅色与深色模式下逐项实测。

## 安装

测试版本不改变 `theme-dist` 所指向的稳定版本。在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.1-test.2
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.1-test.2.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。
