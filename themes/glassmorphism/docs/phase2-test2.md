## 1. 节点卡「剩余 N 天」被裁切

- **根因**：本主题在 `.node-box__row` 上多了一层 `overflow: hidden`。上游只在盒子上裁切，行本身不裁。
  「天」的字形墨迹比字宽多出约 1px，行宽恰好等于字宽时，这部分被行边切掉。
- **修复**：`249483d` 去掉行级裁切，改为与上游相同的盒子级裁切。「剩余 1655 天」「剩余 401 天」「剩余 2 天」实测均为 0px 截断，卡片几何不变。
- **更正**：`v1.1.1-test.1-fix.1` 说明中「上游在同宽度下同样会截断」一句不准确。两边 `scrollWidth` 相同，但裁切发生在不同的层级。以本节为准。

### 2.3 数据与真实性

- **新增历史列**：`processes`、`tcp_conn`、`udp_conn`。CFSM 在长时段按桶内最大值聚合这三列。
- **单位**：内存与磁盘历史以 MiB 上报，图表换算为字节后，按上游 `formatBytes` 显示。
- **缺口**：类目轴只放真实采样。空档超过采样间隔中位数的 2 倍时，插入不带数值的断点标记；上游 `fillMissingTimePoints` 同样会留空值行。断点处的 tooltip 写明「该时段没有采样」。
- **与上游不同、且只因数据真实性而不同的地方**：
  - 缺失值不写成 0（上游写的是 `r.net_in ?? 0`）；
  - 不做 `interpolateNullsLinear` 插值；
  - 「平滑峰值」只改变曲线曲率，不改动数值（上游会用 EWMA 改写数值）；
  - tooltip 中来自节点的文字先转义再输出。
- **延迟任务卡**：上游的统计来自后端接口，CFSM 没有这个接口。平均延迟、P50 / P99、波动率等改由所选时段的历史采样计算，丢包率取丢包列数值点的算术平均，气泡里注明样本数。
- **时间范围**：只列 CFSM 支持的时段。负载区默认 1 天（沿用此前已验收的设置），延迟区默认 1 小时（与上游相同），两区各自独立请求。
- **图表方案**：对齐上游 `CHART_DASHBOARD_PRESETS`，默认包含连接数与进程。上游的显存图和温度图所需的列 CFSM 历史里没有，不收录。本主题独有的磁盘 IO 卡追加在末尾，无数据时不出现。自定义模板支持上游的中文名。

## 3. 厂商

- CFSM 没有厂商字段。作者的意见是不加数据库列，由运营者写进 tags。主题按 tags 约定实现，服务端无需改动。
- 约定格式，以及 CFSM 保存标签时清洗规则的影响（冒号会被删掉、单项 32 字符、最多 12 项），见 [`provider-tags.md`](provider-tags.md)。
- 识别逻辑逐段移植自上游 `providerInfo.ts`。不做 IP / ASN 查询，tooltip 末行注明「ASN / Org 取自节点标签，未做 IP 查询」。
- **图标**：
  - 上游引用的 `simple-icons:linode` 在 Iconify 中不存在，退回为服务器图标；
  - `amazonaws` 和 `tencentqq` 只是别名，这里直接内联解析后的 `amazonwebservices` 和 `qq`。

## 4. 首页核验

### 4.1 丢包显示 0%

- 真实部署三台节点最新一桶的丢包都是 0，显示 0.0% 是真实值。
- 上游首页的丢包数字不是最新一桶，而是整个窗口的加权平均：按探测总数加权，并排除 `loss_approximate`。用同一批窗口数据计算，节点 B 为 1.60%，节点 C为 0.80%，节点 D 为 3.20%。
- 这属于 D-01 口径差异，待裁决（见第 6 节）。

### 4.2 节点卡与上游的偏差（本轮修复）

| 项 | Komari 实测 | 此前 | 现在 |
|---|---|---|---|
| mini 档指标区 | `3fr 2fr`，CPU / 内存只有图标 | `3fr 3fr 4fr` 且带文字，被截成「C...」「内.」 | 与上游相同 |
| 标签文字 / 图标 | `#374151` / Tailwind 500 档 | 文字与图标同色，且为自拟色 | 与上游相同 |
| 提示行 | `#374151` | `#77879a` | 与上游相同 |
| 数值文字 | `#10151c` | `#101722` | 与上游相同 |
| 流量百分比 | 按用量着色（<60 success） | 不着色 | 与上游相同 |
| 进度条 | 纯色 success / warning / destructive，阈值 60 / 80 | 渐变，按「高负载阈值」着色 | 与上游相同 |
| 进度条轨道 | `oklch(0.967 0.001 286.375)` | `rgba(78,102,130,0.13)` | 与上游相同 |
| 指标盒 / 面板 | `rgba(255,255,255,0.15)` | 次要色 6% | 与上游相同 |
| 上行 / 下行 | success / blue-600 | 自拟色 | 与上游相同 |
| 离线遮罩 | 只盖内容区，白色 20%，「离线」字重 600 | 越出卡片 13px 并压住头部 | 与上游相同 |
| 离线红圈 | 实际页面没有（被玻璃样式覆盖） | 有 | 与上游相同 |
| 预设文字色 | 只在节点卡内生效 | 写进全局，总览卡与详情页跟着变色 | 与上游相同 |

深色模式下，同一组 10 项计算值两边完全相同。

**根因**：上游用配色预设的文字色覆盖基础色，但只限 `.node-card` 等玻璃卡片内部；其余元素用 `--foreground` / `--muted-foreground`。
本主题此前把预设文字色写进了全局 `--ink` / `--muted`，而且预设里的色值是自拟的，与上游 `glassTheme.ts` 不同。
现在预设文字色逐字取自上游，并且只在节点卡内部接管；其余地方使用上游的基础色。

## 5. 本地预览说明

国旗 `/flags/<code>.svg` 和系统图标 `/os-icons/…` 由 CFSM 默认皮肤提供，主题开发规范要求第三方主题不重复打包。
本地模拟服务器此前没有这两类文件，所以旗帜位置留白。现在模拟服务器直接读取上游仓库 `public/` 下的同名文件。真实站点不受影响。

## 6. 已知差异与待裁决

1. **D-01 首页丢包口径**：本主题显示最新一桶，上游显示窗口加权平均。待裁决。
2. **配色预设的表面色**（card / control / border）仍是本主题的值。它们驱动顶栏、提示框、面板等上游没有一一对应的界面，整表替换会波及这些界面。
3. **硬件格第三项**：显示 Agent 版本，而不是上游的「虚拟化」。CFSM 不提供虚拟化字段，本主题不放一个永远显示 `-` 的格子。
4. **负载区时间范围**：没有上游的「实时」和「自定义」，因为 CFSM 没有对应的接口。
5. **CHART-003**：仍未复现。新图表的 tooltip 已按上游改为 `confine: false`。
6. **其它卡片尺寸**：comfortable 和 large 两档的行高未在本轮复核，沿用 Test 1 的记录。
